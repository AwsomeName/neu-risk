# Hebbian：假说、现象、模型与算法的区分

修订日期：2026-09-09。旧版“现象为真、算法失败”的二分撤回。本篇用于辨认讨论层次，详细生物证据以[理论笔记](/Users/lc/Desktop/neu-risk/神经网络/0731-Hebbian学习理论与实验验证.md)为准。

## 为什么需要重新区分

“Hebbian 现象”与“Hebbian 学习”不是科学和工程之间的严格术语边界。Hebbian 学习也用于生物机制及计算神经科学。为避免同一个词承担不同论证，本项目区分四层：

| 层次 | 例子 | 如何判断 |
|---|---|---|
| 假说 | 持续参与活动会改变神经元间作用 | 原始论述、可检验预测 |
| 现象 | 某突触在某诱导条件后效能改变 | 实验设计、重复性、因果干预 |
| 模型 | 用局部活动、阈值或时序解释变化 | 假设、推导和预测符合程度 |
| 算法 | 在某网络中用某规则训练 | 泛化、适应、成本和复现 |

现象存在不保证某个解释完整；模型能拟合现象也不保证能训练高性能分类器。工程成绩只能回答其评估协议覆盖的问题。

## 避免跨层跳跃

| 需要避免的跳跃 | 应补充的证据 |
|---|---|
| 观察到可塑性，所以全部学习机制已经证明 | 哪种学习行为、必要性或充分性、其他解释 |
| 某模型效果差，所以相关生物机制无效 | 模型是否准确代表机制，任务是否相关 |
| 修改权重，所以是 Hebbian | 实际更新式及其信息依赖 |
| 增删连接，所以是 Hebbian 结构可塑性 | 连边依据与活动相关性的关系 |
| 相似功能，所以生物与 AI 数学等价 | 方程、变量映射、假设和可检验差异 |

## “生物合理性”如何使用

不再给出没有测量定义的 20%、90% 等总分。可以分别报告：更新是否依赖非局部信息、是否要求对称连接、是否需要阶段切换、神经元与突触模型采用什么简化。满足一个约束不意味着整个系统复制了大脑。

同样，“科学成功 = 可重复”“工程成功 = 准确率”都过窄。科学还涉及解释与预测，工程还可能关心成本、鲁棒性、适应或记忆。评价标准应服从研究问题。
