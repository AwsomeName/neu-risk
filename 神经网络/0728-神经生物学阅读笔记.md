# 神经生物学阅读笔记：问题框架与证据记录

修订日期：2026-09-09。定位：阅读计划与研究问题。旧稿未记录所用《神经生物学》的作者、版次及页码，因此本版按主题组织，不继续声称其章节编号对应某一本已核验教材。

## 阅读目的

理解神经系统怎样处理信息和改变行为，并判断哪些机制值得抽象成计算模型。保留微观和系统两种视角，同时增加两者之间的环路尺度；不因为某个机制有熟悉的 AI 名称，就预设它们相同。

可以先聚焦功能，但当分子或细胞机制决定时间尺度、可用信号与状态变量时，需要补读相应细节。不能一开始就认定这些细节与计算无关。

## 主题与问题

| 主题 | 阅读时记录什么 | 可形成的计算问题 |
|---|---|---|
| 神经元与通信 | 输入整合、状态、发放、复位及适应 | 哪些历史信息必须由状态保留？ |
| 突触可塑性 | 增强/减弱的条件、局部信号、时间尺度 | 哪些更新能由本地信息实现？ |
| 环路与反馈 | 通路方向、信号内容、扰动结果 | 反馈用于推断、控制还是学习？ |
| 竞争与稳定 | 活动约束、阈值和相互作用 | 怎样分工而不失稳？ |
| 记忆与重放 | 活动再现、保持、干扰和更新 | 短时状态怎样影响持久知识？ |
| 内部模拟 | 预测对象、误差、行动选择 | 模拟何时改善决策，何时放大误差？ |
| 发育与结构 | 连边及形态变化、时序、约束 | 结构变化是否提供额外计算收益？ |

## 原来的“对应表”改为假说生成表

| 原来联想到的 AI 机制 | 可以继续问的问题 | 不能直接认定 |
|---|---|---|
| 不应期与 Dropout | 依赖历史的活动抑制能否改善某类系统？ | 二者机制相同或作用等价 |
| 感受野与卷积 | 哪种局部连接与共享约束有效？ | 视觉通路等于一个固定 CNN |
| 工作记忆与模型状态 | 什么信息需要保留，如何读写？ | 人的记忆容量决定 context 长度 |
| 神经调制与奖励/误差 | 哪些细胞接收什么信号，延迟多长？ | 所有调质都是同一个全局标量 |
| 重放与经验回放 | 重放的内容、顺序和时机是否重要？ | 重放一定防止遗忘 |
| CPG 与状态空间模型 | 能否用具体方程表达节律和稳定性？ | 所有 CPG 都是线性 S4 的同构 |
| 结构变化与剪枝 | 何种连边依据改善学习或成本？ | 所有剪枝/NAS 都是 Hebbian |

RNN 是描述循环结构的有效术语，不因出现 Transformer 或状态空间模型就“过时”。不同形式是否适合研究某种动态，应根据问题而非名称判断。

## 三种记录标签

**来源支持：** 具体实验或原文直接支持，并附页码或章节。

**模型解释：** 在明确假设下提出的解释，记录替代模型和预测。

**研究设想：** 从现象产生的工程问题，尚未验证，写清可能的反例。

例：观察到一种活动变化 → 建立解释该变化的模型 → 设计工程消融，这三步应分开记录，不能用一个箭头省略证据。
